# RealmProof

Intent-driven smart contract testing and verification for Gno.land.

> **Status:** Initial development. A public testnet deployment has not yet been verified.

RealmProof combines an English-first Django web studio with reproducible Gno tooling and an example Gno realm.

## Quick start

See `docs/GETTING_STARTED.md` after the application source is committed.

## Hackathon readiness

A working testnet deployment of the Gno component, public demonstration, and verification of end-to-end execution are required before submission. Local simulations alone do not qualify.

RealmProof is an independent project and is not affiliated with Gno.land.
