# Precision design
Use a single horizontal instrument strip for four or more repetitive informational metrics. Combine related counts without hiding labels, values or provenance. Preserve distinct project links and action cards. Decorative rings and rulers are not progress measurements. Use real recorded statuses for outcome colors. Support narrow screens and reduced motion.

Applied to network explorer, native catalog, ledger lab, project summary and run verdict summary. Verify templates and viewport behavior before release.
