# One-click hackathon access
Create the dedicated account once using `python manage.py create_reviewer hackathon_demo_public`. Set runtime secrets REALMPROOF_DEMO_USERNAME=hackathon_demo_public and REALMPROOF_DEMO_PASSWORD to the same password. Never commit the password. The public POST button authenticates server-side and only accepts an active non-staff, non-superuser account with the hackathon_demo_ prefix and exactly one editor membership in a review- workspace. Sessions expire after one hour. Everyone using this button shares the same workspace and can see and modify its demo data. Never store private information there or grant the account access to private organizations. Rate limits and reset automation are not yet implemented.
