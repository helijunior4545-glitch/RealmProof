# Hackathon entry
Provision the dedicated account with python manage.py create_reviewer hackathon_demo_public. Set REALMPROOF_DEMO_USERNAME and REALMPROOF_DEMO_PASSWORD as runtime secrets in the hosting platform. The public POST uses Django authenticate and rejects invalid credentials, staff accounts and accounts outside the single review editor membership. No password is embedded in HTML or source. Failed launches return to the landing page. The shared workspace is mutable by visitors; rate limits and reset automation remain pending.
