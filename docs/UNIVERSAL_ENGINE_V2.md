# Universal Test Engine V2
Run migrations, then start a separate supervised process: python manage.py process_universal --watch. Without a worker jobs remain queued. The default command drains available jobs and exits. PostgreSQL supports concurrent claims with organization row locks; SQLite is single-worker development only. Four active jobs and 30 submissions per rolling 24 hours per organization; one running job per organization. A ten-minute lease marks abandoned jobs inconclusive, without automatic retry. Completion is fenced by a token and atomic with audit insertion. The lease does not kill a stalled process. Existing trusted fixture subprocess timeouts remain in effect. No arbitrary source execution, OS sandbox, global resource cap, or exactly-once execution guarantee. Manual refresh shows queue status. Diagnostic categories are heuristic, not proof of root cause. Existing V1 history is preserved. Deploy web and worker with identical code and database, Gno binary and GNOROOT. Validate migrations and tests on PostgreSQL before production.
