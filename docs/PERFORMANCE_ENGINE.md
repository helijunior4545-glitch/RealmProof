# Performance engine V4.4
90 independent CLI processes with trusted ledger workloads. Wall time includes CLI startup, compilation, execution and output capture; it is not isolated operation latency. Each cycle performs deposit, reserve and settle with state checks. Startup compares zero and one cycle in fresh processes, not controlled cold/warm caches. Gas is the test-level GAS field, not a transaction fee. Missing gas in the gas category invalidates execution. Per-category and equal-workload statistics use nearest-rank P95/P99, median and population standard deviation; small samples are descriptive only. Functional verdict checks state, not performance thresholds. No automatic speedup or performance regression claim without a comparable baseline. Sequential execution, 15-second per-process timeout, 480-second campaign budget, no OS resource isolation. No migration. Runtime validation pending.
