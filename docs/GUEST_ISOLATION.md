# PM6.2 — Opt-in isolated guest foundation

Set REALMPROOF_ISOLATED_GUESTS=1 alongside existing demo credentials to enable. Default remains shared mode. Each successful anonymous launch creates an account with unusable password, independent tenant, project and six trusted scenarios in one transaction. The configured template user row serializes provisioning on PostgreSQL. Lifetime cap of 100 generated accounts; no automatic deletion. Tenant routes using membership_for reject expired (one hour from creation) or unexpected memberships. Organization creation is blocked. Existing public review links and background jobs are not revoked by expiry. No private source should be uploaded. SQLite concurrent provisioning is not supported; production requires PostgreSQL. No per-IP throttling, global execution budget, automatic cleanup, or browser acceptance yet. Keep opt-in disabled until those release gates are reviewed. No deployment changes made.
