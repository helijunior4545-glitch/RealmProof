# Mutation engine V4.1
32 unique first-order trusted ledger mutants, 96 targeted probes per variant and an unmodified baseline. Detection requires successful Gno execution and a false behavioral predicate. Surviving mutants are failed detection checks, not proof of exploitable defects; equivalent mutants are not automatically identified. Runtime errors invalidate the campaign under the existing universal contract. This is a dedicated probe battery, not a score of all V3 campaigns. Fixed 12-second timeout per invocation, 33 invocations maximum; no tenant code. Source, mutant and harness hashes and up to five witness inputs per mutant are retained. No migration. Real runtime validation required.
